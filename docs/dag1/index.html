Open het SQL-werkblad

  1. Het werkblad laadt de database zelf. Rechtsboven verschijnt klaar · database geladen (de eerste keer duurt dat een paar seconden).
  2. Kies links een oefening: die wordt als tabblad geopend. Of typ gewoon je eigen query.
  3. Zet je cursor in een query en druk Ctrl+Enter (Mac: Cmd+Enter).

Links zie je ook alle tabellen met hun kolommen; klik op een kolomnaam om hem in je query te zetten.
